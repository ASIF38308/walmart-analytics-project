# Requirements Register

**Project:** Walmart Centralized Analytics Platform
**Source:** BRD_Walmart_Centralized_Analytics.md, Section 13 (Dashboard Requirements)
**Purpose:** Traces every KPI stakeholders asked for to its actual delivery
status, so nothing is silently dropped or reinterpreted. Updated as
data sources get resolved.

---

## Status Key

- ✅ **Delivered** — built, validated, matches KPI Dictionary definition
- 🟡 **Delivered (Interim)** — built, but not from the officially
  specified source; documented as interim pending real data
- 🔴 **Blocked** — cannot be built; missing data source or unresolved
  methodology, as explained per item

## Caveat: Synthetic Attribution

`order_campaign_attribution` was generated by this project (see
`python/generate_order_campaign_attribution.py`), not sourced from
real click/session tracking data — none exists (DS-007). It simulates
Last-Touch Attribution using a reasonable rule (order date falls
inside an active campaign's window, weighted by campaign spend), but
it is **not real user behavior data**. Every KPI marked "Delivered"
above that depends on this table (Campaign-Attributed Sales,
Operational ROAS, campaign-level Conversion Rate) inherits this
caveat. Treat these as structurally correct and methodologically
sound, but not as ground truth the way Finance-approved numbers would
be.
